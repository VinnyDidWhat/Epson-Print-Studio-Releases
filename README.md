# Epson Print Studio — Windows downloads

[Download the latest Windows installer](https://github.com/VinnyDidWhat/Epson-Print-Studio-Releases/releases/latest)

This repository contains public installers and release notes only. The application source remains private.

## Install and update

1. Open the latest release and download **EpsonPrintStudioSetup.exe**.
2. Run the installer, then open Epson Print Studio.
3. Future updates are offered automatically while the app is running, or use **Updates → Check for updates**.

**No token, GitHub account, or sign-in is required.** Clients on 2.1 or 2.2 without a configured token need one manual installation of 2.3 or later to switch to this public channel.

The app supports drag-and-drop image import, non-destructive cropping, manual positioning, Auto Arrange / Fill Page, PDF export, native Windows printing and ICC color settings. Source image files stay unchanged and must remain available for saved layouts. Print exported PDFs at Actual Size / 100%.

The updater checks installer size and SHA-256 before installation. Windows may request administrator permission. The current layout is preserved before closing for an update.
